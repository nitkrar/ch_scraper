# Phase 1.5 implementation plan

**Companion to:** [`2026-05-27-phase-1.5-design.md`](./2026-05-27-phase-1.5-design.md) — rationale + scope + target structure
**For executor:** read this doc top-to-bottom. The design doc explains *what* and *why*; this doc gives you the *how* — exact commands, exact order, exact verification.

## Hard rules

1. **Code is the source of truth, not this doc.** If during execution you find the code doesn't match a doc claim (e.g. doc says "~50 call sites", you find 47 or 53; doc says a literal is at line X, it's at line Y; you find an inline path construction the doc didn't mention), **trust the code, fold the discrepancy in, fix it, continue**. Note discrepancies in your final handoff post so the doc can be corrected for next time.
2. **Single commit at the end.** All steps below land in ONE git commit at the final step. Intermediate steps run verification but do NOT commit.
3. **No behavioral changes outside the design-approved scope.** Allowed: new `core/paths.py` helpers, call-site rewrites that route through them, new `data/staging/` subdirectory creation, test-fixture move + 3 financials-test path updates, deletion of the memory test. Anything else is out of scope — if you find another problem, note it and skip.
4. **Verify before next step.** Every step has a `Verify:` block. If any verify fails, stop. `git restore` the failing step's changes, fix, re-attempt.
5. **Rollback target.** Step 0 creates a `pre-phase-1.5-bookmark` tag. If anything goes wrong: `git reset --hard pre-phase-1.5-bookmark`.
6. **Do not modify the historical contents of `data/old_staging/`.** Read-only for fixture sourcing in Step 3. The only allowed change there is adding `README.md` plus the matching `.gitignore` exception so that README is tracked.
7. **Ask the user for confirmation** at Step 11 (GUI smoke) and Step 13 (final commit).

def logs_dir(data_dir: Path | str) -> Path:
    return Path(data_dir) / "logs"

def staging_root(data_dir: Path | str) -> Path:

def runs_dir(data_dir: Path | str, sync_type: str) -> Path:

def derived_dir(data_dir: Path | str, domain: str) -> Path:
    return staging_root(data_dir) / "derived" / domain

def archive_dir(data_dir: Path | str, source: str) -> Path:
    return staging_root(data_dir) / "archive" / source

def validation_dir(data_dir: Path | str) -> Path:
    return staging_root(data_dir) / "validation"

### Step 4 — Add `tests/support/paths.py` test helpers

Create `tests/__init__.py` (empty) and `tests/support/__init__.py` (empty) if they don't exist.

Create `tests/support/paths.py`:

```python
"""Test-side path helpers — mirror runtime paths under a temp workspace.

Tests never read from data/staging/ or data/old_staging/ directly. Use
fixture_path() to find tests-owned data, make_test_workspace() to build
a clean isolated tree.
"""
from pathlib import Path
from tempfile import TemporaryDirectory

FIXTURES_ROOT = Path(__file__).resolve().parent.parent / "fixtures"


def fixture_path(*parts: str) -> Path:
    """Resolve a path under tests/fixtures/."""
    return FIXTURES_ROOT.joinpath(*parts)


def make_test_workspace(tmpdir: str | Path, db_name: str = "test.duckdb") -> tuple[Path, Path]:
    """Build a clean (data_dir, db_path) pair under tmpdir for a test.

    Returns (data_dir, db_path) — caller stays responsible for closing
    DuckDB connections and cleaning up tmpdir.
    """
    data_dir = Path(tmpdir) / "data"
    (data_dir / "db").mkdir(parents=True, exist_ok=True)
    db_path = data_dir / "db" / db_name
    return data_dir, db_path
```

## Rollback contract

If any verify fails: stop. `git restore` the failing step's changes. If state is unclear: `git reset --hard pre-phase-1.5-bookmark` returns to the Phase 1 end state.

## Failure modes and recovery

| Symptom | Likely cause | Fix |
|---|---|---|
| Test fails after Step 2 (helper rewrite) | Helper signature doesn't match what call site expected | Read the failing call site, adjust helper or call to match |
| Step 5 fixture copy fails | Exact `07545840.ixbrl` missing from old_staging/ | Stop and surface a blocker. The parser test asserts exact dates from that company; no arbitrary fallback is safe. |
| Step 7 grep finds inline path AFTER rewrites | A site was missed | Apply the helper to it |
| `data/old_staging/README.md` never appears in `git status` | `.gitignore` still ignores it | Add the narrow `!data/old_staging/` / `data/old_staging/*` / `!data/old_staging/README.md` exception, then retry |
| Step 10 baseline diff non-empty | A behavior changed (probably path-resolution edge case) | Read the diff, decide if it's an intentional improvement (document in commit body) or a regression (fix) |
| GUI fails in Step 11 | Probably an import error from helper rewrite in gui.py | Check gui.py top imports + any path constructions |
| Whole phase looks broken | — | `git reset --hard pre-phase-1.5-bookmark` |
